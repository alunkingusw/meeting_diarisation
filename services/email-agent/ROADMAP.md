# Email Agent Roadmap

The project roadmap is maintained centrally so API, backend NLP, and email-agent work share one
architecture and one set of implementation gates. See the
[NLP agent architecture roadmap](../../docs/roadmap.md) for the current baseline and planned
transcript, GitHub, Trello, parent-query, and email-intent phases.

This service README and [Specification.md](Specification.md) describe email-agent behavior and
security requirements; they are not a separate implementation backlog.
